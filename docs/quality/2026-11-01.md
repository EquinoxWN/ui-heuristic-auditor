# Quality check against the 10 rules (2026-11-01)

Run on Windows 11 (Intel Core i7-13700H) with Python 3.14.5, Playwright 1.64.1 and its bundled
Chromium, against the local fixture site. Mutations were applied one at a time by a script that
restores each file.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | fixed | The axe-core download has a 60 s timeout (`axe.py`); page loads and every Playwright call use `--timeout` (`capture.py`). Two gaps fixed: `--timeout 0` was accepted and Playwright treats 0 as no timeout, so one page could hang the audit (now exit 2); and a failed axe download or hash check escaped as a traceback instead of exit 2 (`cli.py` now catches `IntegrityError` and `OSError`). |
| 2 | Writes safe to retry | fixed | Report files are overwritten whole on a re-run. The cached `axe-<version>.min.js` was written in place, and the cache is trusted by its name, so a crash mid-write would have left a truncated script used on every later run. It is now written to a temp file and renamed (`axe.py`, test `test_a_crash_while_caching_never_leaves_a_partial_axe_file`). |
| 3 | No race conditions | N/A | One browser per `Auditor`, used from one thread; each viewport gets its own browser context. |
| 4 | Don't trust the clock | pass | `captured_at` is UTC (`datetime.now(UTC)`, `report.py`); no durations are computed in `src/`. |
| 5 | Read before changing | fixed | `UI_AUDIT_CACHE` (and `--cache`, `--timeout`, `--viewports`) were not documented; the README now lists them. Playwright APIs used exist in 1.64.1 (suite passes). |
| 6 | Never break compatibility | pass | `report.json` keeps `"schema": 1` and its fields; exit codes 0/1/2 unchanged (more errors now map to 2 instead of a traceback). |
| 7 | One source of truth | pass | The axe cache names its source (npm tarball, pinned version and sha512) and is keyed by version, so a new pin fetches and verifies a new file. |
| 8 | Small changes, no secrets, validate input | pass | Secret grep: nothing (the sha512 is a public integrity hash). Only http(s) URLs with a host are audited; page-controlled text is escaped in `summary.md`. |
| 9 | Tests that can actually fail | fixed | No tautologies or skips. 8/9 mutants killed before, 9/9 after. |
| 10 | Re-verify | pass | Results below; CI on push. |
